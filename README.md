# Calculadora de RA

Página sencilla para que los alumnos calculen la nota de un RA. Se escribe cuántos trabajos hay, el peso de cada uno y la nota sacada, y la página hace la cuenta.

Es todo HTML, CSS y JavaScript, sin servidor. Se puede abrir `index.html` directamente en el navegador.

Los tests de la parte del cálculo se lanzan con `node --test`.
